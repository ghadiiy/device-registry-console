# Device Registry Console

## Project Description
A simple Java console application that allows users to manage devices

## Features
- Add new device
- Search for device
- List all devices
- Exit the application
- Validate device information and prevent duplicate IDs

## Requirements
- JDK 21
- Maven

## How to Build
Open a terminal in the project directory and run:

```bash
mvn clean package
```

## How to Run
Run the `Main` class from your Java IDE

## Data Storage
Device records are stored in memory and are not saved after the application exits
